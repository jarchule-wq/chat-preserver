Atlas rclone

A private home backup tool

Atlas rclone is a personal, non-commercial tool. It backs up the owner's family photo library from a home server to the owner's own Google Drive account.

What it does

  • Uploads encrypted copies of the owner's own photo backups to a folder in the owner's own Google Drive.
  • Reads that folder back when the owner needs to restore files or check that the backup is complete.

Who it is for

Only the owner. The app is not offered to the public, and no other Google accounts can or will be connected to it.

Files are encrypted on the home server before upload, so Google Drive only stores encrypted data. No data is sent anywhere except the owner's own Google Drive.

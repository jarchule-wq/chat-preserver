Atlas rclone Privacy Policy

Effective November 21, 2026

Atlas rclone is a private, non-commercial backup tool used only by its owner. This policy explains how it handles Google user data.

Data accessed

With the owner's permission, the app accesses the owner's own Google Drive to create, read, update and delete backup files in a dedicated backup folder. It does not access Gmail, contacts, calendar or any other Google service.

How data is used

Google Drive access is used only to store and restore the owner's own encrypted backups. Files are encrypted on the owner's home server before they are uploaded.

Storage

The OAuth access token is stored only on the owner's home server. Backup files are stored only in the owner's own Google Drive.

Sharing

No Google user data is sold, shared with or transferred to any third party. It is not used for advertising, analytics or AI/ML model training, and no person other than the owner has access to it.

Google API Services User Data Policy

Atlas rclone's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

The 3.0 update and its permissions

After the update, my browser turned Chat Preserver off. Why?

Chat Preserver 3.0 asks for a few new permissions, and Chrome and Edge pause any extension whose update asks for more. Nothing is wrong and nothing was deleted. Open the extensions menu (the puzzle piece), or go to chrome://extensions (edge://extensions in Edge), find Chat Preserver and accept the new permissions. It turns back on with your Pro purchase and settings as they were.

None of these send your chats anywhere. Everything is still saved only on your computer, in Downloads\Chat Preserver or the folder you choose. See the privacy policy.

What gets saved

What does "Back up everything" save?

Every chat and project your account lists, with its messages, files and an offline reader for each chat, plus an index page for the whole backup. ChatGPT and Claude each get their own folder, "ChatGPT backup" and "Claude backup". Later backups save only chats that are new or changed.

What happens when a chat changes?

The chat is saved again in full, into a new folder named with the date and time, next to the earlier copy. In a folder you picked, Chat Preserver keeps the last 5 versions of each chat by default (you can keep all of them or only the newest), and removes an older version only after a newer one has been saved. In Downloads\Chat Preserver nothing is ever deleted, so every version stays until you remove it.

How do I know the backup is complete?

Each saved file gets a SHA-256 fingerprint, and each backup lists what it found and what it saved. Anything the site no longer has, or would not give back, is listed by name with the reason, never silently left out.

The result says "ChatGPT cannot open 1 chat". What is that?

ChatGPT still lists that chat in its sidebar, but its own server answers "not found" when asked for it, so there is nothing to save. Chat Preserver notes it and skips it on later backups, unless the chat changes.

Does it save the AI's thinking?

It saves what the site gives back. ChatGPT gives only a summary of its reasoning, and that summary is saved when there is one. Claude does not return its thinking text to the browser, so it can't be saved.

Scheduled backups

Do scheduled backups need me to click anything?

No, not by default. Scheduled backups save into your Downloads folder, in Downloads\Chat Preserver, and run by themselves with no click. The first backup there is a full one; after that, each backup copies only new or changed files.

Can scheduled backups go to a folder I choose instead?

Yes: in Chat Preserver's settings, choose A folder I pick. Browsers only let an extension keep writing to a folder you picked until the browser is closed, so after each browser restart the first scheduled backup shows a notification. Click it, press Start backup and choose Allow when the browser asks about the folder. Backups then run by themselves until the next restart. If you don't want that click, keep the Downloads option.

Do I need a ChatGPT or Claude tab open?

No. While your browser is open, Chat Preserver opens the site in a background tab at the scheduled time, backs up, and closes the tab. The toolbar button shows RUN while it works. If the browser was closed or the computer asleep at that time, the backup runs soon after you open it.

I back up both ChatGPT and Claude. Do they run at the same time?

They share one schedule and run one after the other, ChatGPT first. If a backup is already running (for example one you started yourself), the scheduled one waits and tries again every 15 minutes, so you may see a tab open and close briefly.

Where do the backups go?

Scheduled backups go to Downloads\Chat Preserver unless you chose a folder yourself. Inside are "ChatGPT backup", "Claude backup" and a page, "Chat Preserver backups.html", that searches the files of both. If you pick your own folder, pick the same one for both accounts (the one that holds them, not one of them) and you get the same page there.

Does Chat Preserver ever delete files from my Downloads folder?

No. It only adds new and changed files there. Old versions stay until you delete them yourself.

Can I stop a backup part-way?

Yes: press "Stop after this chat". The next backup into the same folder continues where it stopped; finished chats are not saved again.

The notification only appears in the Windows notification panel, with no pop-up.

Windows shows pop-ups ("banners") only if they are turned on for your browser: Settings → System → Notifications → Google Chrome (or Microsoft Edge) → turn on "Show notification banners", and check that Do Not Disturb is off. Notifications need no extra permission from you; Windows Focus Assist or Do Not Disturb can hide them.

When ChatGPT asks it to slow down

Why is my first ChatGPT backup slow?

Each chat is read page by page with pauses, so ChatGPT does not slow down or block the backup. Later backups save only chats that changed.

My ChatGPT backup "paused part-way" and says ChatGPT asked it to slow down. What does that mean?

ChatGPT limits how many requests one account can make in a short time (you may see this called "HTTP 429" or "too many requests"). A whole-account backup reads every chat and file, so a large backup, especially the first one, can reach that limit. It is temporary and is not a problem with your account, and nothing already saved is lost. Chat Preserver first waits on its own (2, 5, 10, then 20 minutes) and carries on. If ChatGPT still says slow down after that, the backup pauses:

  • If you started it yourself, press Retry in 1 hour and leave the tab open. It counts down and continues by itself, skipping everything already saved. Or close it and press Back up everything again in about an hour, with the same folder.
  • If it was a scheduled backup, you don't need to do anything. It continues by itself in about an hour (up to three tries).

Find a file and search

Do I need a full backup to find a file?

No. Find a file lists the files across your whole account by name, without downloading them. Tick the ones you want and only those are saved.

How do I search for a file?

Type in the search box in Find a file, or on a backup's index page. A file shows if every word appears in its name, its chat or project, or its kind. You can also use:

  • "budget review" for an exact phrase
  • invoice OR receipt for either one, and -draft (or NOT draft) to leave files out
  • report*.pdf or IMG_????.jpg: wildcards, matched against the whole file name
  • type:pdf, or a group: type:image, video, audio, doc, sheet, slides, code, archive
  • in:budget for the chat or project name, and kind:made (or uploaded, project, shared, inside)
  • after:2026-09-01, before:2026-10, larger:5mb, smaller:200kb

Can it find a file inside a zip?

Yes. A backup lists every file inside each saved zip, and inside a zip within that zip, marked "Inside zip". In Find a file, press Look inside zip files. It downloads the zips to read what they hold, and when you save a file marked "Inside zip", only that file is taken out of its zip.

Save it before the files disappear

ChatGPT doesn't keep your files forever. The charts, spreadsheets and zips it creates while running code expire, and older uploads can vanish too. In one real project we recovered, 35 files were already gone, and nobody can bring those back. Everything ChatGPT still has today, Chat Preserver can save today.

Save a whole ChatGPT project in one run

Open a project in ChatGPT and click once. Chat Preserver saves every chat in the project and every file on its Sources tab into one folder, then writes a project index page linking each chat's reader and each source file. Each chat gets the same full treatment as a single save: transcript, files, checks and its own searchable reader.

If the run is interrupted, start it again with the same folder: chats and files already saved are skipped, and it picks up where it stopped.

Press Back up everything once and Chat Preserver saves every chat and project in your account into one folder, with an index page for all of it. Turn on the nightly schedule and it does it again by itself, saving only what is new or changed. When a chat changes, the new copy goes into a dated folder next to the old one, so earlier versions are kept.

What makes it different

The files, not just the words

Uploads, images and the files ChatGPT created while running code are downloaded and linked where they appear.

Checked, not hoped

The chat is captured twice, two different ways, and the captures are compared. Anything ChatGPT no longer has is listed by name, never silently dropped.

Proof you can keep

Every file gets a SHA-256 fingerprint, and the whole chat gets a content fingerprint that stays the same each time you save an unchanged chat.

A reader, not a dump

One offline page with search, filters, jump-to-message, a side rail for long chats, images inline and working file links.

Private by design

Runs in your browser and saves to a folder you choose. No account, no server, nothing uploaded.

Works on work accounts

ChatGPT Team, Enterprise and Edu workspaces have no built-in export. If you can open the chat in your browser, you can save it.

Quick or Full

Quick saves every message and the reader in about 20 seconds. Full adds every file in a few minutes, and can run later into the same folder.

Polite to ChatGPT

Downloads are paced, slow down automatically if ChatGPT asks, and pick up where they left off.

Good to know before you start

  • Files ChatGPT creates expire. Files made while ChatGPT runs code (charts, spreadsheets, zips) are kept by ChatGPT for a limited time. Save chats with generated files soon. Expired files can't be recovered by anyone; the reader lists them by name.
  • Deleted or unavailable files can't be recovered. If ChatGPT no longer has a file, it's listed as missing, never faked.
  • It saves what the site still has. Edited messages and regenerated answers are saved as the site keeps them. Anything already discarded is gone. ChatGPT sends only a summary of its thinking, and Claude sends none, so the AI's full thinking can't be saved.
  • Scheduled backups need your browser open. If the browser is closed or the computer asleep at backup time, the backup runs soon after you open it. The first one may ask you to allow the folder; see the FAQ.
  • Desktop browser, signed in. Chrome or Edge on a computer. It only saves chats your account can open.
  • Quick mode doesn't download files. Run Full later into the same folder to add them.
  • Keep the tab open. Closing the tab or putting the computer to sleep stops the run. Start again with the same folder to resume; finished chats are not saved again.
  • It depends on ChatGPT's and Claude's websites. If OpenAI or Anthropic changes how their site works, saving may stop working until an update is released.
  • Work accounts are your responsibility. Check your organization's policy before saving work chats.
  • You keep the copy safe. Everything is saved only on your computer. We never see it, so we can't restore it if you lose it.
  • What the fingerprints prove. They show a saved file hasn't changed since it was saved. They don't certify what ChatGPT said for legal purposes.

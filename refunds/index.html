Before you ask for a refund

Many problems have a quick fix. If a recovery stopped or a file didn't save, write to us with the run's evidence/run_report.json file. It contains the steps and error messages, not your chat text.

Some files can't be recovered by anyone: files ChatGPT has deleted or let expire. Chat Preserver lists them by name, so you know exactly what's missing. That's how ChatGPT works rather than a fault, but if it means Pro isn't useful to you, the 14-day refund still applies.
